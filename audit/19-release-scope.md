# リリース範囲と判定条件（2026-10-06・1.1.0）

対象はBOOTH-Reader 1.1.0（未コミット作業ツリー。`core/version.py` = `1.1.0`、基準 `main` / HEAD `b249833`）。HEADだけでは候補を識別できない。固定候補の識別情報・実行証拠は候補外の `audit/release-checklist-current.md` と `.cache/` に集約し、Git配布対象に含めない。

**テスト・デバッグの合格条件は、ユーザー指示（2026-10-06）により「Windows機とSSH接続したMacでテストが通ること」とする。** 両環境で全テストと独立クローン検証が合格し、ローカル候補の最終判定はリリース準備完了。ライセンスゲートの `READY FOR RELEASE` は第三者物の配布条件・入力一致の判定であり、製品の全必須条件は本表のR01〜R15で別に確認する。公開（commit/push）は未実施の別操作。

## 製品・配布範囲

- 利用者: 自分のBOOTH購入品を整理する個人。CLIを処理の本体とし、loopback限定のWeb UIを提供する。
- 配布: GitHubリポジトリのクローン。本体MIT、第三者物はそれぞれの原文と `THIRD_PARTY_TERMS.md` に従う。ソース公開と同梱バイナリの再配布条件は別に確認する。
- 環境: Windows 11/10 x64（build 17763以降）とApple Silicon Mac（macOS 14以降）、書込み可能なローカルディスク。検証はWindows 11 x64とmacOS 27（SSH接続）で実施し、宣言最低OSの実機・別PC・長時間運転は追加の検証範囲外（ユーザー合格条件）。
- 前提: WindowsはOS標準PowerShell・.NET Frameworkと同梱CPython 3.12.13・SQLite 3.53.4・固定62wheel・WebView2。MacはOS標準ツールと同梱CPython 3.12.15・固定62wheel・自作MIT WebKitホスト。追加ランタイム導入、管理者権限、利用者側のコンパイルを要求しない。
- 通信: 初期化・起動・修復はオフライン可。BOOTH/pixiv認証、購入一覧・ファイル・商品画像の取得、WebView2のSmartScreen等は外部通信を伴う。
- 対象外: Intel Mac・Windows ARM64/x86・Linux、UNC/NASからの直接実行、公開サーバー・複数ユーザー運用、FBXプレビュー、VCC、常駐自動分類、別形式の配布アーカイブ、ストア提出、署名証明書の購入。既存の範囲・配布方式に基づく。
