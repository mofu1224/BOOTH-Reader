# 義務解析

監査日: 2026-10-02。判定: **BLOCKED**。

- MIT/ISC: 著作権・許諾・免責の原文保持。
- BSD: source/binary条項に沿った原文保持、BSD-3では権利者名のendorsement不可。
- Apache-2.0: LICENSEと該当NOTICE、改変通知、著作権保持、特許許諾/終了条項。商標許諾は別。
- PSF: LICENSE/著作権保持、派生変更要約。Windows追加条件はMITへ統合しない。
- MPL: 対象ファイルのSource Code Formと入手案内。certifi同版sdistを同梱。別版の内蔵certifiを同じsdistで充足しない。
- LGPL: COPYING保持だけでなく実バイナリに対応したソース・改変・リンク条件の充足。FFmpegは現行payloadから除外し、旧配布物/履歴は未許可。
- Tcl/Tk/Tix/複合データ/独自条件: 実原文を保持し適用範囲の閉包を特定。
個別Commercial Use/Redistribution/Patent/Trademark判断は台帳の未確認項目を維持。
